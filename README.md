# Table Extraction Python

First MVP structure for:
- OCRParse ingestion
- layout reconstruction
- Klippa compatible JSON generation

## Run

```bash
python main.py
```

## Input

Place OCRParse JSON in:

```text
test_documents/ocrparse.json
```

## Output

Generated file:

```text
test_documents/generated_klippa_result.json
```
